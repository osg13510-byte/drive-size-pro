🔒 Privacy & Data Safety

安心のローカル完結設計
（100% Client-Side）

Drive Size Pro は外部サーバーを一切持たず、すべての処理をユーザーのブラウザ内だけで完結します。

🛡️ 読み取り専用の最小権限

要求するのは drive.metadata.readonly（ファイル名・サイズ等のメタデータのみ）と drive.appdata（ユーザー自身のドライブ内非表示キャッシュ領域）のみ。ファイル本文や中身には一切アクセスしません。

Only read-only metadata (drive.metadata.readonly) and your private appDataFolder cache (drive.appdata) are accessed. File contents are never read or downloaded.

🚫 外部サーバーへの送信ゼロ

取得したフォルダ構成や容量データはブラウザ内のローカルストレージにのみ保持され、開発者サーバーや第三者へ送信・共有・販売されることは一切ありません。

All processing runs 100% client-side in your browser. Zero data is transmitted to external developer servers, third parties, advertisers, or AI models.

📜 Google API ポリシー完全準拠

Google API Services User Data Policy（Limited Use 要件）を厳守しています。設定画面または Google アカウント設定からいつでもキャッシュ削除・連携解除が可能です。

Use of Google APIs strictly adheres to the Google API Services User Data Policy, including the Limited Use requirements.
