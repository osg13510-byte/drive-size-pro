プライバシーポリシー / Privacy Policy

はじめに / Introduction

Drive Size Pro（以下「本拡張機能」）は、ユーザーの Google Drive 上でフォルダやファイルの容量を直接計算・可視化する無料のブラウザ拡張機能です。本拡張機能はユーザーのプライバシー保護を最優先に設計されており、すべてのデータ解析処理をユーザーのブラウザ内（100% クライアントサイド）で完結させます。

English Summary: Drive Size Pro is a free browser extension that calculates and visualizes folder sizes directly inside Google Drive. It operates 100% client-side within your browser and never transmits, stores, or sells your Google Drive data to any external developer server or third party.

1. アクセスする Google ユーザーデータ / Google User Data Accessed

本拡張機能は、Google Drive の容量分析機能を提供するために必要な最小限の権限（OAuth 2.0 スコープ）のみを要求します。ファイルの中身（文書本文、画像、動画データ等のコンテンツ自体）をダウンロードしたり閲覧したりすることは一切ありません。

OAuth 2.0 スコープ / Scope アクセス内容と利用目的 / Purpose & Data Accessed
https://www.googleapis.com/auth/drive.metadata.readonly Google Drive 内のフォルダ・ファイルのメタデータ（名前、ファイルサイズ、MIMEタイプ、更新日時、親フォルダID、共有権限情報）のみを読み取り専用で取得します。ファイルの変更・削除・作成およびファイル本文の取得は一切行いません。
(Read-only access strictly to file/folder metadata—name, size, MIME type, modified date, parent IDs, and sharing permissions—to calculate folder sizes, detect duplicates, and visualize storage usage. File contents are never accessed or downloaded.)
https://www.googleapis.com/auth/drive.appdata ユーザーが任意に「クラウド保存」機能を使用した場合や解析結果を高速復元するために、ユーザー自身の Google Drive 内のアプリ専用非表示フォルダ（appDataFolder）に解析キャッシュファイル（drivesize_cache.json）のみを保存・取得します。
(Stores and restores your local scan cache JSON strictly inside your own private Google Drive App Data folder so you do not need to re-scan large drives across sessions.)

2. データの利用目的 / How We Use Google User Data

  • Google Drive の画面上に各フォルダ・ファイルの合計容量や更新状況を表示するため
  • カテゴリ別（動画・画像・書類など）のドーナツチャート、ツリーマップ、ヒートマップ、大容量ファイルのランキングを表示するため
  • ユーザー自身のブラウザ画面上で重複ファイル候補や共有設定の一覧を可視化し、ユーザー自身の操作により CSV ファイルとしてローカル端末へ書き出すため
English: Retrieved metadata is strictly used inside your browser session solely to display folder sizes, category breakdown charts, treemaps, duplicate file lists, sharing status summaries, and user-initiated local CSV exports.

3. データの保存・セキュリティ・第三者提供の禁止 / Data Storage, Protection & Sharing

  • ローカル完結処理（100% Client-Side）: API から取得したメタデータおよび計算キャッシュは、ユーザー端末のブラウザ内ストレージ（chrome.storage.local / chrome.storage.session）およびユーザー自身の appDataFolder にのみ保存されます。
  • 外部サーバー送信なし（No External Servers）: 開発者が管理する外部サーバーへの送信・蓄積、解析用トラッキング、Cookie 収集は一切行っていません。
  • 第三者提供・広告・AI学習利用の禁止: ユーザーの Google データを第三者へ共有、販売、貸与すること、および広告配信、与信判断、汎用的な AI/ML モデルの学習に利用することは一切ありません。
  • 通信の暗号化と最小権限: Google Drive API との通信はすべて HTTPS（TLS）で暗号化され、アクセストークンは読み取り専用およびアプリ専用領域に限定して利用されます。
English: All data processing takes place locally in your browser. Cached results are stored exclusively in browser local/session storage and your own Google Drive appDataFolder. No developer backend servers exist, and no Google user data is ever transferred to third parties, sold, used for advertising, or used to train AI/ML models.

4. Google API Services User Data Policy への準拠 / Limited Use Compliance

Limited Use Requirements Compliance Declaration

Drive Size Pro's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

本拡張機能による Google API から取得した情報の使用および他のアプリへの転送は、限定的使用（Limited Use）要件を含め、Google API Services User Data Policy に完全に準拠します。

5. データの削除と権限の取り消し / Data Retention, Deletion & Revoking Access

  • キャッシュの即時削除: 拡張機能のポップアップまたは分析パネル内「設定」タブにある「キャッシュクリア・再計算」ボタンを押すことで、ブラウザ内および appDataFolder 上の解析キャッシュをいつでも完全に削除できます。
  • 拡張機能のアンインストール: 拡張機能をブラウザから削除すると、ローカルストレージに保存されていたすべての設定とキャッシュは自動的に消去されます。
  • Google アカウント連携の解除: ユーザーはいつでも Google アカウントの権限設定（myaccount.google.com/permissions） から「Drive Size Pro」のアクセス権限を取り消すことができます。
English: You can delete all cached data at any time using the "Clear Cache" button in the extension or by uninstalling the extension. You can revoke Google Drive API access at any time from your Google Account Permissions page.
